# Linux Installation Practice

This file contains my practice notes for installing Linux operating system on a virtual machine during my Linux System Administration training.

## Installation Steps
- Downloaded Linux ISO image  
- Created virtual machine using VirtualBox / VMware  
- Configured system resources (RAM, CPU, Disk)  
- Booted system using ISO file  
- Completed Linux installation setup  

## Post Installation Tasks
- Created user account  
- Set root password  
- Checked system version  
- Updated system packages  

## About
This practice reflects my understanding of Linux installation process and basic system setup required for system administration tasks.
