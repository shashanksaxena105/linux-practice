# RHEL Version Identification Practice

This file documents how to identify the RHEL version.

## Checking Red Hat Release
Command:
cat /etc/redhat-release

Example:
$ cat /etc/redhat-release
Red Hat Enterprise Linux release 10.0 (Coughlan)

Description:
Shows installed RHEL version.

---

## Checking System Release
Command:
cat /etc/system-release

Example:
$ cat /etc/system-release
Red Hat Enterprise Linux release 10.0 (Coughlan)

Description:
Alternative method to verify OS version.

---

## Objective
This practice helps in identifying Linux distribution and version.
