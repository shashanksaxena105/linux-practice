# Linux Navigation and File Operations Practice

This file documents my hands-on practice with directory navigation and basic file operations in Linux.

## Print Working Directory
Command:
pwd  

Example:
$ pwd  
/root  

Description:
Shows the current working directory.

---

## Listing Files and Directories
Command:
ls  

Example:
$ ls  
Desktop  Documents  Downloads  

Description:
Lists files and folders in the current directory.

---

## Changing Directories
Command:
cd /home  

Example:
$ cd /home  
$ pwd  
/home  

Description:
Moves into the /home directory.

---

## Moving Back and Home
Commands:
cd ..  
cd ~  

Example:
$ cd ..  
$ cd ~  

Description:
Moves one level up or returns to home directory.

---

## Creating Files
Command:
touch testfile  

Example:
$ touch testfile  
$ ls  
testfile  

Description:
Creates an empty file.

---

## Creating Directories
Command:
mkdir myfolder  

Example:
$ mkdir myfolder  
$ ls  
myfolder  

Description:
Creates a new directory.

---

## Absolute and Relative Paths

Absolute Path Example:
cd /data/a1/a2  

Relative Path Example:
cd ../..  

Description:
Demonstrates navigation using absolute and relative paths.

---

## Objective
This practice demonstrates my understanding of Linux directory structure, navigation commands, and basic file management operations.
