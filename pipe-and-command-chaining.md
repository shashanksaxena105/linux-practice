# Pipe and Command Chaining Practice

This file documents use of pipe and semicolon.

## Semicolon (;)
Command:
date ; cal

Description:
Executes multiple commands sequentially.

---

## Pipe (|)
Commands:
lsblk | wc -l
lsblk | grep disk

Description:
Passes output of one command as input to another.

---

## Objective
This practice demonstrates command chaining and piping.
