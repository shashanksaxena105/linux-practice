# Linux Filesystem Navigation Practice

This file documents my hands-on practice with Linux filesystem navigation commands.

## Listing Root Directory
Command:
ls /

Example:
$ ls /
bin  boot  dev  etc  home  lib  lib64  root  usr  var

Description:
Displays the top-level directories of the Linux filesystem.

---

## Listing Root User Home Directory
Command:
ls /root

Example:
$ ls /root
Desktop  Documents  Downloads

Description:
Lists files and directories inside the root user's home directory.

---

## Home Directory Shortcut
Command:
ls ~

Example:
$ ls ~
Desktop  Documents  Downloads

Description:
Shows contents of the current user's home directory using ~ shortcut.

---

## Objective
This practice demonstrates understanding of Linux filesystem hierarchy and navigation.
