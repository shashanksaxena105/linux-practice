# Text Processing Commands Practice

This file documents text processing utilities.

## Viewing File Content
Commands:
cat /etc/passwd
cat -n /etc/passwd

---

## Head and Tail
Commands:
head -n 5 /etc/passwd
tail -n 5 /etc/passwd

---

## Grep Command
Command:
grep root /etc/passwd

---

## Word Count
Commands:
wc /etc/passwd
wc -l /etc/passwd
wc -w /etc/passwd
wc -c /etc/passwd

---

## Objective
This practice demonstrates Linux text processing tools.
