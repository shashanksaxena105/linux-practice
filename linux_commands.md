# Linux Basic Commands Practice

This file contains my practice notes for basic Linux command line operations learned during Linux System Administration training.

## Directory & File Commands
- pwd       : Show current directory  
- ls        : List files and directories  
- cd        : Change directory  
- mkdir     : Create new directory  
- rmdir     : Remove empty directory  

## File Operations
- touch     : Create empty file  
- cp        : Copy files  
- mv        : Move or rename files  
- rm        : Remove files  

## File Viewing Commands
- cat       : Display file content  
- head      : View first lines of file  
- tail      : View last lines of file  

## Package Management (Basics)
- apt install / yum install : Install packages  
- apt update / yum update   : Update system packages  
- apt remove / yum remove   : Remove packages  

## About
This practice reflects my hands-on learning in Linux installation, command line usage, file handling and basic system administration tasks.
